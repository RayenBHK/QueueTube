# Report a QueueTube security issue

This guide explains which versions receive fixes and how to report a vulnerability without exposing users before a patch exists.

## Supported versions

Security fixes target the current `main` branch and the latest tagged release.

## Send a private report

Use GitHub's private vulnerability reporting feature for this repository. Include the affected version, reproduction steps, impact, and a suggested fix when you have one.

Do not open a public issue for an unpatched vulnerability. Use a public issue for normal defects that do not expose data, execute unintended code, or bypass QueueTube's controls.

## Expected response

The maintainer will confirm receipt, reproduce the issue, and coordinate disclosure after a fix is available. Response time depends on maintainer availability.
